wörds language pack specification

wörds learns from language packs: words, verb forms and lections in a .linguapack file. This specification describes that format completely, so that packs can be made and edited outside the app, in a web app, a desktop editor or a converter from other formats.

Versions

The format version is the number packs carry in formatVersion. Version 1 is the only one so far, and the folder v1/ describes it. A later format version gets a folder of its own, and v1/ stays as it is for the packs written in version 1.

The specification itself has revisions, listed at its end. A revision makes the text clearer or more complete; it never changes what a valid version 1 pack is, unless the app changed, in which case the revision says so.

The specification describes what the app actually does. A test in the app's repository checks this repository: the schema copy against the generated schema, the templates and conformance cases against the app's validator, and the issue-code catalogue against the app's codes.

Building

The archives of the templates and of the archive-level conformance cases, and the template index, are generated from the folders next to them:

python3 tools/spec/build-spec.py           # write the archives and the index
python3 tools/spec/build-spec.py --check   # check that they are up to date (CI)

The HTML pages are built with the rest of the site: python3 tools/docs/build-manual.py.
