Issue codes of the wörds language pack format

Every problem a reader finds in a pack, an archive or a repository index has a stable code. This page lists all codes of format version 1 with their severity and meaning, and how to fix them. The rules behind them are in the format specification; the conformance cases show most of them on a small pack.

  • Error: the pack (or index) is rejected. Warning: it is accepted; strict validation treats warnings as errors.
  • Codes are never renamed or reused. A new reader version may add codes: an app that meets a code it does not know shows the issue's English message instead.
  • The path of an issue names the file and the JSON path of the value, such as pack.json:$.content[0].entries[2].term, or content/verbs.json:$.verbs[1].id for an included file. Archive issues name the archive file; content.duplicate-item and content.duplicate-card name the content type.

Archive

Reported while a .linguapack archive is extracted. The first one stops the import.

CodeSeverityMeaning and fix
archive.corruptErrorThe archive cannot be read: it is cut off, encrypted, uses an unsupported compression method, has a stored entry with a data descriptor, or has entry names that are not UTF-8. Write it again with a standard zip writer.
archive.emptyErrorThe archive has no file entries, or the file is not a zip archive at all.
archive.unsafe-pathErrorAn entry name is absolute, contains .., ., an empty segment, \, : or NUL, or is longer than 255 characters. Use relative paths with /.
archive.duplicate-entryErrorTwo entries have the same name.
archive.too-many-filesErrorMore than 10,000 entries.
archive.too-largeErrorMore than 100 MiB uncompressed.
archive.compression-ratioErrorThe archive expands to more than 100 times its size (checked after the first MiB): it looks like a zip bomb. Store media instead of compressing them, and keep JSON free of huge repetitive content.

Files

The set of files in the pack, included files and referenced pictures and recordings.

CodeSeverityMeaning and fix
files.symlinkErrorThe pack folder contains a symbolic link. Replace it with the file.
files.too-manyErrorMore than 10,000 files.
files.pack-too-largeErrorAll files together exceed 100 MiB.
files.disallowed-typeErrorA file that is not .json, .opus, .m4a, .mp3, .png, .webp or a LICENSE, LICENSE.md, LICENSE.txt, NOTICE or README.md. Often .DS_Store or Thumbs.db: leave them out.
files.missingErrorpack.json, an included file or a referenced file does not exist. Paths are case-sensitive and relative to the pack root.
files.too-largeErrorpack.json or an included file is larger than 5 MiB. Split the content into more included files.
files.unsafe-pathErrorAn include or a reference is not a safe relative path.
files.include-not-jsonErrorAn entry of includes does not end in .json.
files.wrong-kindErrorA referenced file has the wrong extension for its field: image takes .png or .webp, audio takes .opus, .m4a or .mp3.
files.content-mismatchErrorThe file's bytes do not match its extension, or a picture has no readable header. Convert the file instead of renaming it.
files.image-too-largeErrorA picture is larger than 1 MiB.
files.image-dimensionsErrorA picture is wider or taller than 2,048 pixels.
files.image-animatedErrorA picture is animated (APNG or animated WebP). Use a still picture.

Syntax

Reading pack.json and included files.

CodeSeverityMeaning and fix
syntax.invalid-jsonErrorNot valid JSON: a byte order mark, a comment, a trailing comma, single quotes, or broken text.
syntax.schemaErrorThe JSON does not have the expected structure: an unknown field, a missing required field, a value of the wrong type, or an included file that holds something other than one object. Compare with the schema.
syntax.string-too-longErrorA string is longer than 1,000 characters after NFC normalization.
syntax.control-characterErrorA string contains a control character other than line feed or tab, such as a carriage return.

Manifest

manifest.invalid-idErrorThe pack id is not lowercase segments of letters and digits joined by ., _ or -, or longer than 100 characters.
manifest.invalid-versionErrorThe version is not a semantic version such as 1.0.0.
manifest.blank-titleErrorThe title is empty or only white space.
manifest.missing-licenseWarningNo license is declared. Add an SPDX identifier, or NONE.
manifest.invalid-languageErrorsourceLanguage, targetLanguage or tts.locale is not a language tag such as de, pt-BR or zh-Hant-TW.
manifest.same-languagesErrorSource and target language have the same primary language, such as de and de-AT.
manifest.tts-language-mismatchWarningtts.locale is in another language than the target language.
manifest.no-directionsErrorsupportedDirections is an empty list. Leave it out for both directions.
manifest.invalid-directionErrorA direction is neither source->target nor target->source.

sections.invalid-idErrorA section id does not match the id pattern, or is longer than 100 characters.
sections.duplicate-idErrorTwo sections have the same id.
sections.blank-titleErrorA section title is empty or only white space.

Content

CodeSeverityMeaning and fix
content.emptyErrorThe pack has no content blocks, inline or included.
content.missing-typeErrorA content block has no string type.
content.unknown-typeWarningA block has a type the reader does not know; it is skipped.
content.no-supported-typeErrorNo block of a type the reader knows is left.
content.duplicate-itemErrorTwo blocks of the same type define an item with the same id. Reported when the pack is installed.
content.duplicate-cardErrorTwo blocks of the same type define the same card. Reported when the pack is installed, together with content.duplicate-item.

Repository index

Reading lingua-index.json. The first four reject the whole index; the others skip one entry, so the rest of the repository stays available.

CodeSeverityMeaning and fix
index.too-largeErrorThe index is larger than 1 MiB.
index.syntaxErrorThe index is not valid JSON, or a required field is missing or has the wrong type.
index.unsupported-versionErrorindexVersion is not 1.
index.too-many-packsErrorThe index lists more than 1,000 packs.
index.duplicate-idWarningA pack id is listed more than once; the first entry is used.
index.invalid-idWarningAn entry's id is not a valid pack id.
index.unsafe-pathWarningAn entry's path leaves the repository folder.
index.invalid-extensionWarningAn entry's path does not end in .linguapack, or has characters other than A–Z, a–z, 0–9, ., _, - and /.
index.invalid-versionWarningAn entry's version is not a semantic version.
index.unsupported-formatWarningAn entry's format version is not supported.
index.invalid-sha256WarningAn entry's checksum is not 64 hex digits.
index.invalid-languageWarningAn entry's source or target language is not a language tag.
index.no-content-typesWarningAn entry lists no content types.
index.invalid-content-typeWarningA content type is not an id of at most 50 characters.
index.invalid-titleWarningAn entry's title is blank, longer than 200 characters, or contains control characters other than line feeds.
index.invalid-descriptionWarningAn entry's description is longer than 1,000 characters or contains control characters other than line feeds.
index.invalid-sizeWarningAn entry's size is not between 1 byte and 100 MiB.

Download

Checked after a pack is downloaded from a repository, before it is imported.

CodeSeverityMeaning and fix
download.size-mismatchErrorThe archive's size differs from sizeBytes in the index. Generate the index from the final archives.
download.sha256-mismatchErrorThe archive's SHA-256 differs from sha256 in the index.
download.index-mismatchErrorThe archive's pack id or version differs from the index entry.

Import

Checks of the app when it installs a pack that is valid in itself.

CodeSeverityMeaning and fix
import.user-pack-conflictErrorA pack with a user. id came from a repository, and the learner has an editable pack with that id. Publish packs under ids without the user. prefix.
import.not-editableErrorA local file with a user. id cannot become an editable pack: it has no vocabulary entries, an entry id is used twice, a title is longer than 100 characters, or a picture has no description. See section 13 of the specification.
